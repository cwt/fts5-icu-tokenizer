# Bug 25 — Unit tests ran under ReleaseFast, blinding safety checks

**File:** `build.zig`
**Severity:** LOW

## Description

`optimize` defaulted to `.ReleaseFast` and `addTest` inherited the root
module's mode, so `zig build test` ran without safety checks: integer
overflow, OOB slicing, and other panic-checked UB classes were compiled
out precisely where the regression suite should catch them. Leak detection
still worked, but e.g. a reintroduced bug-#10-class heap overflow would no
longer trap in tests.

## Impact

- Weakened regression protection; previously fixed bug classes could pass
  the suite silently if reintroduced.

## Fix

Dedicated `test_root_module` (same sources/imports as the universal
library) with `.optimize = .Debug` for `addTest`; shipped libraries keep
ReleaseFast. Suite: 34/34 passing.

**Status:** ✅ FIXED.
