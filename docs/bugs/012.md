# Bug 12 — Dead code: u_strFromUTF8 resolver and icu_funcs entry

**Files:** `src/c_icu.zig`, `build.zig`
**Severity:** LOW

## Description

After [Bug 7](007.md) replaced the ICU two-pass `u_strFromUTF8` probe with
`std.unicode.utf8ToUtf16LeAllocZ`, `u_strFromUTF8` is never called anywhere.
Its resolver in `c_icu.zig` and its entry in the `icu_funcs` list in
`build.zig` were dead. (`u_strToUTF8` / `u_strToUTF8WithSub` are still
actively used — only `u_strFromUTF8` was dead.)

## Impact

- No runtime effect; a few lines of dead code plus an unnecessary assembly
  alias in every artifact.

## Fix

Removed the resolver and dropped the `icu_funcs` entry. The live
transliteration path (rule string → std UTF-16 conversion → utrans →
UTF-8) is covered by a dedicated unit test proving no `u_strFromUTF8`
dependency remains.

**Status:** ✅ FIXED — d22f41c6.
