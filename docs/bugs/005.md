# Bug 5 — Dead code: getSuffixForLocale / LocaleInfo.suffix

**File:** `src/rules.zig`
**Severity:** LOW

## Description

`LocaleInfo.suffix` was populated for every locale but never read —
library file names come from `build.zig` via `b.fmt("fts5_icu_{s}", ...)`,
not from this field. `getSuffixForLocale` was only called from the
`rules.zig` unit test.

## Impact

- None at runtime; pure maintenance noise.

## Fix

Removed `suffix` from `LocaleInfo`, removed `getSuffixForLocale`, and
dropped the corresponding test assertion.

**Status:** ✅ FIXED — 34113613.
