# Bug 24 — build.zig duplicate artifacts when -Dlocale names a loop locale

**File:** `build.zig`
**Severity:** LOW

## Description

With `-Dlocale=ja` (any of the eight loop locales), the top-level
conditional libraries were named `fts5_icu_ja` / `fts5_icu_ja_legacy` —
exactly what the unconditional per-locale loop also built and installed.
Each colliding artifact compiled twice and installed to the same
`zig-out/lib` path (last install silently wins). Byte-equivalent today,
but a silent-overwrite hazard if the option sets ever diverge.

## Impact

- Wasted double compilation; future-divergence overwrite hazard.

## Fix

The per-locale loop `continue`s when the locale equals `-Dlocale`, leaving
those two artifacts to the top-level libraries. Default build still
installs all 36 libraries.

**Status:** ✅ FIXED.
