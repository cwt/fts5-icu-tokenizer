# Bug 43 — Test harness defects in test_all_legacy.sh, lint-check.sh, and test_universal_tokenizer.sql

**File:** `scripts/test_all_legacy.sh`, `scripts/lint-check.sh`, `tests/test_universal_tokenizer.sql`
**Severity:** LOW (test harness & integration test accuracy)

## Description

1. **`scripts/test_all_legacy.sh` never exits non-zero on test failure:**
   [Bug 33](033.md) added `FAILED=0`, `${PIPESTATUS[0]}`, and `exit 1` to `scripts/test_all.sh`, but `scripts/test_all_legacy.sh` (which is the script executed by all five container builds in `README.md`) was left unpatched:
   - Error branches (`if [ $? -ne 0 ]`) echo `ERROR: Test failed...` without setting `FAILED=1` or exiting non-zero.
   - Line 118 (`sed ... | $SQLITE3 | sed -e 's/|/ /g'`) does not inspect `${PIPESTATUS[1]}` for `$SQLITE3`'s exit status.
2. **`scripts/lint-check.sh` is missing `set -e` and skips 4 source files:**
   `scripts/lint-check.sh` runs `zig ast-check` on only 3 files (`fts5_icu.zig`, `tokenizer.zig`, `rules.zig`) without `set -e`, omitting `c_icu.zig`, `compat.zig`, `test_transliterator.zig`, `locale_specific_tests.zig`, and `test_locale_tokenizer.zig` (as well as `build.zig`).
3. **Stale `'russkij'` query in `tests/test_universal_tokenizer.sql`:**
   Line 26 runs:
   ```sql
   SELECT * FROM test_universal_v2 WHERE test_universal_v2 MATCH 'russkij';
   ```
   Since [Bug 14](014.md) switched Russian transliteration from `Cyrillic-Latin` to `Russian-Latin/BGN` with `й -> y`, `'русский'` indexes as `'russkiy'`, whereas ASCII `'russkij'` tokenizes as `'russkij'` and matches 0 rows.

## Impact

- Legacy/container test runs in CI exit 0 even when SQLite tests fail, `lint-check.sh` can succeed when `ast-check` fails on earlier lines, and the Russian query in `test_universal_tokenizer.sql` silently returns no match.

## Suggested fix

- Port `FAILED=0`, `${PIPESTATUS[1]}`, and `exit 1` to `scripts/test_all_legacy.sh`.
- Add `set -e` and all `.zig` files to `scripts/lint-check.sh`.
- Update `MATCH 'russkij'` to `MATCH 'russkiy'` in `tests/test_universal_tokenizer.sql`.

## Implemented

Track test failures and exit non-zero in test_all_legacy.sh, add set -e and all zig files to lint-check.sh, and update query to russkiy in test_universal_tokenizer.sql

Verified with `zig build test` on both Zig 0.16.0 and Zig 0.17.0.

**Status:** ✅ FIXED.
