# Bug 42 — Remaining code duplication across rules.zig, tokenizer.zig, and build.zig

**File:** `src/rules.zig`, `src/tokenizer.zig`, `build.zig`
**Severity:** LOW (code duplication / maintainability)

## Description

Follow-up to [Bug 34](034.md) covering remaining duplicated logic across the codebase:

1. **Rule-feature sniffing duplicated between `rules.zig` and `tokenizer.zig`:**
   `rules.zig` (`infoFor`, ~32–40) and `tokenizer.zig` (`transliterateString`, ~132–134) both scan a rule string for `"Russian-Latin/BGN"`, `"Arabic-Latin"`, and `"Hebrew-Latin"`. Exposing `pub fn sniffRuleFeatures(rule_set: []const u8)` in `rules.zig` keeps rule-string inspection in one place.
2. **Supported language aliases duplicated between `rules.zig` and `tokenizer.zig`:**
   `rules.zig` (`getLocaleInfo`, ~55–62) and `tokenizer.zig` (`isValidLocaleLanguage`, ~362) both list the 13 language codes/aliases (`"ja"`, `"jp"`, `"zh"`, `"cn"`, `"th"`, `"ko"`, `"kr"`, `"ar"`, `"ru"`, `"he"`, `"iw"`, `"el"`, `"gr"`). Exporting `isSupportedLanguageAlias` from `rules.zig` eliminates the drift risk.
3. **Buffer growth helper in `tokenizer.zig`:**
   Growing an optional heap fallback buffer (`if (heap_buf) |hb| realloc else alloc`) is repeated across the pre-transliteration retry loop and the two `destBuf` growth sites.
4. **Include paths and artifact definitions in `build.zig`:**
   - `linkModule` (~110–111) repeats `/usr/include` and `/usr/local/include` instead of calling `addIncludes(mod, macos)`.
   - Creating a tokenizer shared library (`addOptions` + `createModule` + `linkModule` + `addLibrary` + `configureArtifact` + `installArtifact`) is repeated 4× (~129–236), and creating a test runner executable is repeated 3× (~266–330).

## Impact

- Maintenance and drift hazard when adding new locales, rules, or build flags.

## Suggested fix

Factor the shared helpers in `rules.zig`, `tokenizer.zig`, and `build.zig` without changing external behavior or exported symbols.

## Implemented

Factored duplicated logic across `rules.zig`, `tokenizer.zig`, and `build.zig`:
1. Exposed `pub fn sniffRuleFeatures(rule_set: []const u8) RuleFeatures` in `src/rules.zig`, eliminating duplicated feature scanning between `rules.infoFor` and `tokenizer.transliterateString`.
2. Exported `pub const supported_aliases` and `pub fn isSupportedLanguageAlias(lang: []const u8) bool` from `src/rules.zig`, eliminating alias duplication between `rules.zig` and `tokenizer.isValidLocaleLanguage`.
3. Reused `growHeapBuf` in `src/tokenizer.zig` for `destBuf` initial allocation and growth in `tokenizeText`.
4. Refactored `build.zig`: reused `addIncludes(mod, macos)` in `linkModule`, added `addTokenizerLibrary` helper consolidating 4 duplicated dynamic library targets, and added `addTestRunner` helper consolidating 3 duplicated test executable targets.

Tests: added unit tests in `src/rules.zig` for `sniffRuleFeatures` and `isSupportedLanguageAlias`. Verified unit test suite (59/59 passed) on both Zig 0.16.0 and Zig 0.17.0, verified full build graph snapshot equivalence against pre-refactor artifacts and steps on both toolchains, and verified SQLite integration tests.

Verified with `zig build test` on both Zig 0.16.0 and Zig 0.17.0.

**Status:** ✅ FIXED.
