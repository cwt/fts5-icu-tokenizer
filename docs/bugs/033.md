# Bug 33 — Test harness cannot fail

**File:** `scripts/test_all.sh`
**Severity:** LOW (testing)

## Description

Two defects combine to keep the suite permanently green:

1. The universal TH/ZH check pipes sqlite3 through `sed`, so `$?` belongs
   to `sed` — that test can never fail (previously noted in
   [minor notes](minor-notes.md), now formally filed).
2. Every `ERROR: Test failed` branch only echoes and continues; the script
   exits 0 even when tests fail. The `tests/*.sql` scripts also set no
   `.bail on`, relying on modern sqlite3 CLIs exiting non-zero on SQL
   errors.

## Impact

- Regressions in the SQLite-level suite pass CI silently; only
  `zig build test` actually gates.

## Suggested fix

`set -euo pipefail` (or capture `${PIPESTATUS[0]}`), `exit 1` on the
failure branches, and add `.bail on` to the SQL scripts.

**Status:** OPEN.
