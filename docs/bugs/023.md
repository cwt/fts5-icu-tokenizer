# Bug 23 — Dead build_options import in tokenizer.zig

**File:** `src/tokenizer.zig`
**Severity:** LOW

## Description

`const build_options = @import("build_options");` was never referenced. It
compiled only because Zig analyzes imports lazily. The three test
executables import `tokenizer.zig` through module graphs that do **not**
provide `build_options` — working purely by accident. The first real use
would have failed those three build steps with a missing-module error.

## Impact

- None now; a confusing delayed compile error later.

## Fix

Deleted the import (preferred over wiring `build_options` into the three
test-executable modules). All three test-executable steps still build and
run.

**Status:** ✅ FIXED.
