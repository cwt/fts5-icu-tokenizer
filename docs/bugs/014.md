# Bug 14 — Cyrillic-Latin collapses distinct letters; й maps to i

**File:** `src/rules.zig`
**Severity:** HIGH

## Description

`Cyrillic-Latin` maps щ/ш/с → `s` and ж/з → `z` (combining marks stripped
by the later `Latin-ASCII` step), so distinct words collapsed: борщ/борс →
`bors`, шар/сар → `sar`, жар/зар → `zar`. Additionally ICU's
`Russian-Latin/BGN` maps й (U+0439) → `i` while BGN/PCGN specifies `y`, so
мой/мои → `moi`. Verified by probe on ICU 78 and 67.1.0.

## Impact

- Russian full-text search unreliable: unrelated words share tokens,
  distinct inflections indistinguishable; token spellings change vs the old
  output.

## Fix

- Switched `ICU_RULE_RU` and the Cyrillic leg of `ICU_RULE_DEFAULT` to
  `Russian-Latin/BGN` (plain `Russian-Latin` does not exist on ICU 67).
- Pre-map й/Й to `y` in the UTF-16 domain before transliteration (1:1
  units, position map stays exact), gated on the rule string. Inline
  transliterator pre-rules are impossible: `utrans_openU` accepts only
  registered compound IDs.
- Rejected: `Cyrillic-Latin/BGN` and `/UNGEGN` (still emit diacritics),
  `NFD; remove-marks` (still collapses), per-token transliteration (UBRK
  splits before transliteration).

**Status:** ✅ FIXED — 05c52e983470.
