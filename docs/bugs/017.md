# Bug 17 — ICU < 69 fallback ignored the per-call override locale

**File:** `src/tokenizer.zig`
**Severity:** LOW

## Description

On platforms without `ubrk_clone` (ICU < 69, non-Darwin), `tokenizeText`
re-opened a break iterator with `tokenizer.locale_slice`, ignoring the
per-call `override_locale`. The transliterator and (on newer ICU) the
cloned iterator used the override, but the fallback iterator used the
tokenizer's own locale.

## Impact

- Override calls segmented differently on ICU < 69 vs ≥ 69.

## Fix

Use the effective locale (non-empty override wins, else the tokenizer's
own) in the fallback branch, matching the transliterator logic.
