# Bug 11 — Dead resolver: icu.ubrk_clone never called

**File:** `src/c_icu.zig`
**Severity:** LOW

## Description

The `icu.ubrk_clone` resolver existed but was never invoked —
`tokenizeText` used `c.ubrk_clone` directly, with versioned-symbol
resolution handled by the assembly alias in `build.zig` instead:

```zig
const pBreakIterator = if (build_options.has_ubrk_clone)
    c.ubrk_clone(baseBreakIterator, &clone_status) // <-- bypasses resolver
```

In fact there was no live resolver at all; the actual resolution lived in
generated assembly.

## Impact

- No runtime effect; dead code plus an inconsistent call path.

## Fix

Added a real resolver alongside every other ICU call and switched
`tokenizeText` to it (`icu.ubrk_clone`), for consistency.

**Status:** ✅ FIXED — 4e980f79.
