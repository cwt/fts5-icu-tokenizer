# Bug 13 — All 35 entrypoints compiled into every locale library

**File:** `src/fts5_icu.zig`
**Severity:** LOW

## Description

The `entrypoints` comptime table lists all 35 symbols, and the `comptime`
block exported all of them from every library. Each locale `.so` (e.g.
`libfts5_icu_ja.so`) therefore exported all 35 entrypoints instead of just
its own 4; the universal lib exported all 35 instead of its 3 — contradicting
the original C build, where each `.so` is compiled once per locale.

## Impact

- Binary bloat (~34 dead exports per library). No runtime impact; SQLite
  only invokes the entrypoint matching the loaded stem.

## Fix

Filter the table at comptime with `build_options.locale`: universal exports
the 3 non-locale-specific symbols, each locale library its own 4. Verified
with `nm` and the `entrypoint export set matches build locale` unit test.

**Status:** ✅ FIXED — 27e7cbf4.
