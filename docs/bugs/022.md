# Bug 22 — Pre-ICU-69 builds impossible although the fallback exists

**Files:** `src/c_icu.zig`, `src/tokenizer.zig`
**Severity:** LOW

## Description

The `ubrk_clone` resolver hard-errored via `@compileError` when the
headers predated `ubrk_clone`, yet `tokenizeText` carries the non-clone
`ubrk_open` fallback written precisely for those old ICU versions — dead
by construction. Additionally `has_ubrk_clone` was defined twice with
different-but-equivalent expressions (drift-prone).

## Impact

- No effect on supported platforms; blocked any build against genuinely
  old ICU and invited gate drift.

## Fix

`c_icu.zig` declares the canonical function type itself and resolves
`ubrk_clone: ?UbrkCloneFn` via `@extern`, degrading to `null` (no
`@compileError`) on old ICU. `has_ubrk_clone` is exported once from
`c_icu.zig` and consumed by `tokenizer.zig`; the call site unwraps the
optional behind the gate.

**Status:** ✅ FIXED.
